Xuélù Chinese — offline Chinese learning app
============================================

Use it right away
  Double-click index.html. It opens in your browser and works with no internet.
  Your progress is saved in that browser.

Install it like an app (phone or computer)
  Put this folder on any web host (GitHub Pages, Netlify, your own server), open the
  address once while online, then choose "Install" / "Add to Home Screen".
  After that it runs fully offline, including the fonts.

Audio
  Pronunciation uses your device's Chinese (Mandarin) voice, which works offline.
  If you hear nothing, install a Chinese voice:
    Windows: Settings > Time & language > Speech > Add voices > Chinese (Simplified)
    Android: Settings > Google Text-to-speech > Install voice data > Chinese
    iPhone / Mac: Settings > Accessibility > Spoken Content > Voices > Chinese

Adding content
  All patterns, explanations and sentence templates are plain data in the source files.
